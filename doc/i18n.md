# i18n (fordítás)

Greenfield: [uj-projekt.md](uj-projekt.md) → i18n lépés.  
Admin kinézet/működés (hol jelennek meg a stringek): [admin-oldal.md](admin-oldal.md).

## Szabály (minden prefix)

1. **Minden** látható / statikus UI szöveg `__()` (vagy `__d()`) hívásban legyen — Admin, Member, közös layout/element, Flash, hibaoldalak.
2. A **msgid angol** (fordítási forrásnyelv), pl. `__('Save')`, `__('Samples')`.
3. A megjelenő nyelv a **locale** szerint jön a `.po` fájlokból.
4. JS nem tud `__()`-t: a lefordított stringeket PHP adja át (`MyAdmin.messages` a layoutban; oldalspecifikus címkék a `scriptBlock` configban `json_encode` + `__()`).
5. Admin böngésző dialógusok: **SweetAlert2** (`MyAdmin.alert` / `alertError` / `confirmDelete`); a Swal szövegek is a `MyAdmin.messages`-ből jöjjenek (`errorTitle`, `okButton`, …) — ne hardkódolt magyar a JS-ben, és **ne** `window.alert`.
6. **Számok megjelenítése** (index/view/modal): `LocaleNumberParser::format()` a aktuális locale szerint (Admin: `hu_HU` → `1 234,56`). A `__()` csak címkékre — msgid angol.
7. Soha ne hardkódolj magyar (vagy más célnyelvű) UI stringet a templatebe „gyorsabbnak” — mindig `__()` + .po.

## Locale

| Kontextus | Locale |
|-----------|--------|
| App default | `hu_HU` (`config/app.php` → `App.defaultLocale`) |
| Admin prefix | mindig `hu_HU` (`LocaleMiddleware` + `Admin\AppController`) |
| Member prefix | URL `{lang}` → `LocaleMiddleware` (`config/languages.php`) |

Adminban **nincs** nyelvválasztó a headerben.

## Fájlok

```
resources/locales/default.pot          # extract forrás (bin/cake i18n extract)
resources/locales/hu_HU/default.po     # magyar fordítások
```

Új szövegek felvétele:

```bash
bin/cake i18n extract --extract-core no --overwrite --merge yes --output resources/locales --paths src,templates
# majd egészítsd ki a hu_HU/default.po msgstr értékeit
# segéd: php tmp/build_hu_po.php  (ha a map naprakész)
```

## Példák

```php
<?= __('Save') ?>
$this->Flash->success(__('The sample has been saved.'));
$this->Paginator->sort('name', __('Name'));
```

```php
// Layout: MyAdmin.messages
'deleteConfirm' => __('Do you really want to delete the selected record?'),
```
