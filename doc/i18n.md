# i18n (fordítás)

Greenfield: [uj-projekt.md](uj-projekt.md) → i18n lépés.  
Admin kinézet/működés: [admin-oldal.md](admin-oldal.md).  
Éles playbook: [minta-tanulsagok.md](minta-tanulsagok.md) §0.2.

## Szabály (minden prefix)

1. **Minden** látható / statikus UI szöveg `__()` (vagy `__d()`) hívásban legyen — Admin, Member, közös layout/element, Flash, hibaoldalak.
2. A **msgid angol** (fordítási forrásnyelv), pl. `__('Save')`, `__('Samples')`.
3. A megjelenő nyelv a **locale** szerint jön a `.po` fájlokból.
4. JS nem tud `__()`-t: a lefordított stringeket PHP adja át (`MyAdmin.messages` a layoutban; oldalspecifikus címkék a `scriptBlock` configban `json_encode` + `__()`).
5. Admin böngésző dialógusok: **SweetAlert2** (`MyAdmin.alert` / `alertError` / `confirmDelete`); a Swal szövegek is a `MyAdmin.messages`-ből jöjjenek (`errorTitle`, `okButton`, …) — ne hardkódolt magyar a JS-ben, és **ne** `window.alert`.
6. **Számok megjelenítése** (index/view/modal): `LocaleNumberParser::format()` az aktuális locale szerint (Admin hu → `1 234,56`). A `__()` csak címkékre — msgid angol.
7. **Pénz megjelenítés:** `LocaleNumberParser::formatCurrency()` — mindig **HUF**, ICU locale szerint (hu: `… Ft` utótag; en: `HUF …` előtag; de/fr/sk: `… HUF`). **Nem** `__('Ft')` / kézi `format()`+szuffixum. Más valuta: `$currency` param.
8. Soha ne hardkódolj magyar (vagy más célnyelvű) UI stringet a templatebe „gyorsabbnak” — mindig `__()` + .po. Kivétel a locale formázók (`format`, `formatCount`, `formatCurrency`).

### Gyakori Admin msgid-ek (lapozó / kereső)

| Msgid | hu_HU példa |
|-------|-------------|
| `Back to top` | Vissza a tetejére |
| `Pagination` | Lapozás |
| `First` / `Previous` / `Next` / `Last` | Első / Előző / Következő / Utolsó |
| `Page {{page}} of {{pages}}, showing {{current}} record(s) out of {{count}} total` | bake counter (placeholderek maradnak) |
| `Start search` / `Clear search` | Keresés indítása / Keresés törlése |
| `Search in the text fields of this list.` | Index tooltip magyarázat |

9. Dátum picker / szám inputmask formátum: `LocaleDateParser::jsConfig()` / `LocaleNumberParser::jsConfig()` — követi az Admin locale-t ([middleware.md](middleware.md)).

## Locale

| Kontextus | Locale |
|-----------|--------|
| App default | `hu_HU` (`config/app.php` → `App.defaultLocale`) |
| **Admin prefix** | `App.adminLocale` (`config/app.php` / `APP_ADMIN_LOCALE`) — **éles: `hu_HU`** |
| Member prefix | URL `{lang}` → `LocaleMiddleware` (`config/languages.php`) |

Beállítás (egy helyen):

```php
// config/app.php
'adminLocale' => env('APP_ADMIN_LOCALE', 'hu_HU'),
```

Használat:

- `LocaleMiddleware` — Admin prefix → `I18n::setLocale(App.adminLocale)` (szám/dátum middleware előtt)
- `Admin\AppController::initialize()` — ugyanez

Ideiglenes EN UI/teszt: `en_US` (vagy `.env`). **Éles indulás előtt vissza `hu_HU`.**

Adminban **nincs** nyelvválasztó a headerben.

Új szövegek felvétele:

```bash
bin/cake i18n extract --extract-core no --overwrite --merge yes --output resources/locales --paths src,templates
# majd egészítsd ki a hu_HU/default.po msgstr értékeit
# segéd: php tmp/build_hu_po.php  (ha a map naprakész)
```

## Országnevek (DB Translate)

UI stringek ≠ adatbázis tartalom. Az **országnevek** a `countries` + `i18n` táblákban vannak (nem `.po`).

| Tábla / mező | Tartalom |
|--------------|----------|
| `countries.name` | Angol kanonikus név (pl. `Hungary`) |
| `countries.iso2` | ISO 3166-1 alpha-2 (`HU`) |
| `countries.locale` | Az ország **elsődleges** locale-ja (`hu_HU`, `de_DE`, `en_US`, …) |
| `continents` | Földrészek: angol `name` + `code` (AFR/ASI/…) |
| `countries.continent_id` | FK → `continents.id` (CakePHP: `belongsTo Continents`) |
| `i18n` (Continents) | Translate EAV: `model=Continents`, `field=name` — CLDR földrésznévek **minden** Countries-locale-ra; Admin UI locale szerint jelenik meg |
| `countries.visible` / `pos` | **Egyedül ezek** szerkeszthetők Adminban |
| `i18n` (Countries) | Translate EAV: `model=Countries`, `field=name` — **csak megjelenítés** (UI locale); Admin formon **nincs** fordítás-szerkesztő; **index/modal soha ne sorolja fel** az i18n sorokat |

Admin: `/admin/countries` — lista / view / edit; edit = csak **Visible** + **Position**. Nincs add / delete / i18n form. Lista később **continent** szerint csoportosítható.

```php
$countries = $this->fetchTable('Countries');
$countries->getBehavior('Translate')->setLocale(I18n::getLocale());
$countries->Continents->getBehavior('Translate')->setLocale(I18n::getLocale());
$hu = $countries->find()->contain(['Continents'])->where(['Countries.iso2' => 'HU'])->first();
// hu_HU → Magyarország + Európa; de_DE → Ungarn + Europa; en_* → Hungary + Europe
```

Seed:

```bash
php tmp/seed_continents.php   # continents + i18n + countries.continent_id
# (országok: php tmp/seed_countries.php ha van)
```

### Árva i18n sorok tisztítása

A Translate EAV polimorf (`model` + `foreign_key`) — nincs DB FK. Törölt szülő után maradhat árva sor.

```bash
bin/cake cleanup_i18n_orphans           # törli az árvákat
bin/cake cleanup_i18n_orphans --dry-run # csak számol
# vagy: php tmp/cleanup_i18n_orphans.php
```

| `i18n.model` | Szülő tábla |
|--------------|-------------|
| `Countries` | `countries` |
| `Continents` | `continents` |

Ismeretlen `model` érték → az összes ilyen sor törlődik. Árva = `foreign_key` nincs a szülő `id`-k között.

### Index lapozó counter (bake)

Az Admin index lábléc (`admin/index_footer`) a Cake bake formátumot használja — a **msgid angol**, a placeholderek benne maradnak (a Paginator cseréli ki fordítás után):

```php
$this->Paginator->counter(
    __('Page {{page}} of {{pages}}, showing {{current}} record(s) out of {{count}} total')
);
```

`.po` példa (hu):

```
msgid "Page {{page}} of {{pages}}, showing {{current}} record(s) out of {{count}} total"
msgstr "{{page}}. oldal / {{pages}}, megjelenítve: {{current}} rekord, összesen: {{count}}"
```

Ha a `countries.id` értékeket újra kell számozni (pl. 1-től):

```bash
php tmp/renumber_countries_ids.php
```

A script az `i18n` (`model=Countries`) `foreign_key` mezőit **ugyanazzal az offsettel** frissíti, hogy a fordítások ne szakadjanak el.
